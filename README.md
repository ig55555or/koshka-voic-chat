# 🐱 Кошкина видеосвязь

Голос, видео с камеры, трансляция экрана и текстовый чат с друзьями — на компьютере, iPhone и Android.
Сервер — Python в Docker, клиент — браузер (Chrome, Edge, Яндекс, Safari).

Репозиторий: https://github.com/ig55555or/koshka-voic-chat
```bash
git clone https://github.com/ig55555or/koshka-voic-chat.git
```

## Что умеет

| Функция | Как сделано |
|---|---|
| **Шифрование** | WebRTC DTLS-SRTP, сквозное. Весь трафик идёт **через ваш сервер** (TURN), но сервер пересылает уже зашифрованные пакеты и прочитать их не может. Вход в комнату по паролю. |
| **Проверка от перехвата** | «Код безопасности» в меню собеседника (клик по нику). Если цифры у вас и у друга совпадают — посредника нет. |
| **Шумоподавление** | ИИ (RNNoise, как Krisp) / стандартное браузерное / выкл. + шумовой гейт и выравнивание громкости голоса. |
| **Громкость** | Клик по нику → 0–400% для голоса и звука трансляции, «заглушить для меня». Свой микрофон 0–400%. Лимитер — без хрипа. |
| **Устройства** | Выбор микрофона, динамиков и камеры (на телефоне — кнопка «Сменить»: фронтальная / задняя). |
| **Камера** | Везде, качество 360p / 720p / 1080p. Своё видео показывается зеркально, как в Discord. |
| **Трансляция экрана** | Только с компьютера (телефоны не дают сайтам захватывать экран). До 1440p 60 FPS, со звуком. |
| **Телефон** | Отдельная раскладка: участники сверху, видео во весь экран, крупные кнопки снизу, чат — выезжающей панелью. Экран не гаснет во время звонка. |
| **Темы** | 🌸 / 🌙 — тёмная или розовая. 🐱 — кошачий режим: ушки, лапки, «мяу» вместо писков. Переключаются прямо во время звонка. |
| **Ещё** | Mute / Deafen (Ctrl+Shift+M / Ctrl+Shift+D), индикатор «говорит», пинг, до 8 человек в комнате. |

**iPhone:** открывайте в Safari (или в Chrome — на iOS это тот же движок). Во время звонка не сворачивайте
браузер и не блокируйте экран — iOS ставит звук на паузу; при возврате звук и микрофон восстановятся сами.

## Аккаунты, гости и администратор

| | Гость | Аккаунт | Администратор 👑 |
|---|---|---|---|
| Вход | имя | логин и пароль (без почты) | логин и пароль |
| Чужая комната | по паролю | по паролю | без пароля |
| Своя комната | исчезает, когда все вышли | сохраняется, вход без пароля | сохраняется |
| Список комнат | нет | свои | все, кто онлайн, удаление любой |

Администратор виден участникам. Создать его можно только на сервере (пароль спросит в терминале):
```bash
bash run.sh admin ЛОГИН
```
Забыли пароль: `bash run.sh passwd ЛОГИН`. Закрыть регистрацию: `ALLOW_REGISTRATION=0` в `.env` и снова `run.sh`.

Аккаунты и комнаты лежат в docker-томе `voice-data`. Обновление и `run.sh stop` его не трогают,
а `docker compose down -v` удалит все аккаунты.

## Запуск на Linux-сервере в Docker (за Caddy)

Скопируйте папку проекта на сервер, зайдите в неё и выполните:
```bash
bash run.sh voice.ваш-домен.ru
```
Скрипт соберёт и запустит контейнер `voice-chat` и выведет блок для Caddyfile.
Сам Caddy он не трогает — только смотрит, как тот запущен:

| Как запущен Caddy | Что делает скрипт | В Caddyfile |
|---|---|---|
| `network_mode: host` | открывает порт только на `127.0.0.1:18080` | `reverse_proxy 127.0.0.1:18080` |
| в своей docker-сети | подключает voice-chat к этой сети | `reverse_proxy voice-chat:8080` |

Порт меняется в `.env` (`VOICE_PORT`). Повторный запуск той же команды — обновление.
Ещё: `bash run.sh logs` (логи), `bash run.sh stop` (остановить).
WebSocket и `X-Forwarded-For` Caddy проксирует сам, больше ничего настраивать не нужно. Для домена нужна A-запись на IP сервера.

**Весь трафик через сервер.** Скрипт сам поднимает TURN-сервер (coturn): определяет внешний IP,
генерирует ключ, а браузеры получают временные пароли на 12 часов. По умолчанию прямые соединения
выключены (`RELAY_ONLY=1` в `.env`), и звук, экран и чат идут только через сервер.

⚠️ Обязательно откройте порты, иначе соединение не установится:
`3478/udp`, `3478/tcp`, `5349/tcp`, `49160-49200/udp`.

**Мобильный интернет.** Многие операторы режут обычный TURN (порт 3478). Поэтому сервер поднимает ещё и
TURN поверх TLS на порту 5349: для сети он выглядит как обычный HTTPS. Нужен сертификат домена: скрипт
берёт уже выпущенный Caddy (только читает его том). Запускайте `run.sh` с доменом. Caddy продлевает
сертификат сам, а coturn читает его при старте, поэтому добавьте в crontab `0 5 * * 1 docker restart voice-coturn`.
Проверить связь с устройства: ⚙️ → «Проверить связь с сервером». Их нужно открыть и в фаерволе сервера, и в панели хостера, если там есть свой фаервол.
Логи TURN: `bash run.sh turnlogs`.

## Запуск на Windows

1. Нужен **Python 3.10+** (у вас уже стоит).
2. Двойной клик по **`start.bat`** (первый раз сам поставит зависимости).
3. Откройте адрес, который он напишет, например `https://localhost:8443`.
   Браузер предупредит о сертификате (он самоподписанный) → «Дополнительно» → «Перейти на сайт».

Или вручную:
```bash
pip install -r requirements.txt
python server.py
```

## Как подключить друга через интернет

Браузер даёт доступ к микрофону только по **HTTPS**, поэтому есть два пути:

**Вариант А — проще всего, без настройки роутера (Cloudflare Tunnel):**
```bash
python server.py --no-tls --port 8080
cloudflared tunnel --url http://localhost:8080
```
`cloudflared` выдаст адрес вида `https://xxxx.trycloudflare.com` — отправьте его другу.
Скачать cloudflared: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
(Через туннель идёт только сигналинг, сам голос всё равно идёт напрямую P2P.)

**Вариант Б — свой сервер / проброс порта:**
пробросьте порт 8443 на роутере (или запустите на VPS) и запустите с вашим внешним IP/доменом в сертификате:
```bash
set CERT_HOSTS=ВАШ_IP_ИЛИ_ДОМЕН
python server.py
```
(если папка `certs` уже есть — удалите её, чтобы сертификат пересоздался.)

Дальше вы оба открываете адрес, вводите **одно и то же название комнаты и пароль**. Первый зашедший задаёт пароль.

### Если не соединяется (висит ⏳)
Так бывает, когда у обоих строгий NAT (мобильный интернет, некоторые провайдеры). Нужен TURN-сервер — например, бесплатный coturn на VPS:
```bash
set TURN_URL=turn:ваш-сервер:3478
set TURN_USER=user
set TURN_PASS=pass
python server.py
```

## Советы
- Используйте **наушники** — так не будет эха.
- Для трансляции игры со звуком в Chrome выберите «Весь экран» и включите «Также поделиться системным звуком».
- Чтобы друг не слышал сам себя в вашей трансляции, обновите Chrome/Edge до свежей версии.
