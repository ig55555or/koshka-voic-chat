# 🐱 Кошкина видеосвязь

**Свой маленький Discord на своём сервере: голос, камера, экран и чат прямо в браузере.**

Ничего не нужно устанавливать: друг открывает ссылку и уже в звонке. Работает на компьютере, iPhone и Android.

## ✨ Возможности

|  |  |
|---|---|
| 🎙️ **Голос** | Шумоподавление ИИ (RNNoise, как Krisp), шумовой гейт, выравнивание громкости: тихий друг станет слышен |
| 📷 **Камера** | 360p / 720p / 1080p, на телефоне можно переключать фронтальную и заднюю |
| 🖥️ **Трансляция экрана** | До 1440p 60 FPS со звуком (с компьютера) |
| 💬 **Чат** | Текстовые сообщения прямо в комнате, тоже зашифрованы |
| 🔊 **Громкость каждого** | Нажмите на ник: от 0 до 400% для голоса и трансляции отдельно, «заглушить для меня» |
| 🎧 **Устройства** | Выбор микрофона, динамиков и камеры, проверка микрофона «слышать себя» |
| 🔒 **Шифрование** | Сквозное: сервер пересылает пакеты, но прочитать их не может. Есть код безопасности для сверки с другом |
| 👤 **Аккаунты** | Быстрая регистрация без почты, гости без регистрации, администратор 👑 |
| 🪪 **Профиль** | Фото с обрезкой (или эмодзи), цвет, статус и «о себе». Меняется прямо в звонке, у всех обновляется сразу. Рядом с ником виден `@логин`, так что выдать себя за другого не выйдет |
| 🛡️ **Модерация** | Админ-панель: баны на время или навсегда, разбан, права админа, объявления всем. Выгнать из комнаты может админ и создатель комнаты |
| 🔑 **Комнаты с паролем** | Пароль спрашивают один раз, дальше аккаунт его помнит |
| 📱 **Телефон** | Отдельная раскладка с крупными кнопками, экран не гаснет во время звонка |
| 🌸 **Темы** | Тёмная 🌙 или розовая 🌸, а ещё **кошачий режим** 🐱: ушки, лапки и «мяу». Переключаются прямо во время звонка |
| 🩺 **Диагностика** | Кнопка «Проверить связь с сервером» покажет, что режет сеть: UDP, TCP или TLS |

> Горячие клавиши: **Ctrl+Shift+M**, чтобы выключить микрофон, и **Ctrl+Shift+D**, чтобы выключить звук.
> В комнате может быть до 8 человек.

## 🚀 Запуск на сервере за 60 секунд

Понадобятся Linux-сервер с **Docker**, домен с A-записью на IP сервера и **Caddy** (или другой обратный прокси с HTTPS).

```bash
git clone https://github.com/ig55555or/koshka-voic-chat.git /opt/voice-chat
```
```bash
cd /opt/voice-chat
```
```bash
bash run.sh voice.example.com
```

Вместо `voice.example.com` укажите свой домен. Скрипт сделает всё сам:

- ✅ соберёт и запустит контейнер `voice-chat`;
- ✅ поднимет TURN-сервер (coturn), сам определит внешний IP и сгенерирует ключ;
- ✅ найдёт сертификат Caddy для TURN поверх TLS (только читает его, ничего не меняет);
- ✅ выведет готовый блок для Caddyfile.

**Ваш Caddy скрипт не трогает**, он только смотрит, как тот запущен:

| Как запущен Caddy | Что добавить в Caddyfile |
|---|---|
| `network_mode: host` | `reverse_proxy 127.0.0.1:18080` |
| в своей docker-сети | `reverse_proxy voice-chat:8080` (скрипт сам подключит контейнер к этой сети) |

```caddy
voice.example.com {
    reverse_proxy 127.0.0.1:18080
}
```

### 🧱 Откройте порты

Без них звонок не соединится. Порты нужно открыть и в фаерволе сервера, и в панели хостера, если там есть свой.

| Порт | Зачем |
|---|---|
| `3478/udp`, `3478/tcp` | TURN: пересылка звука и видео |
| `5349/tcp` | TURN поверх TLS: для мобильного интернета, где обычный TURN режут |
| `49160-49200/udp` | каналы для звонков |

Caddy продлевает сертификат сам, а coturn читает его только при старте. Поэтому добавьте в `crontab -e`:
```
0 5 * * 1 docker restart voice-coturn
```

### 🛠️ Команды

| Команда | Что делает |
|---|---|
| `bash run.sh домен` | запуск и обновление |
| `bash run.sh admin ЛОГИН` | создать администратора, пароль спросит в терминале |
| `bash run.sh passwd ЛОГИН` | сменить пароль аккаунта |
| `bash run.sh logs` | логи сервера |
| `bash run.sh turnlogs` | логи TURN |
| `bash run.sh stop` | остановить (аккаунты сохранятся) |

## 👥 Аккаунты, гости и администратор

|  | 🙂 Гость | 👤 Аккаунт | 👑 Администратор |
|---|---|---|---|
| **Вход** | только имя | логин и пароль, без почты | логин и пароль |
| **Список комнат** | — | видит все | видит все и кто в них сейчас |
| **Чужая комната** | по паролю | по паролю один раз, дальше без пароля | без пароля |
| **Своя комната** | пропадает, когда все вышли | сохраняется, вход без пароля | сохраняется |
| **Удаление** | — | своих комнат | любых |
| **Выгнать / выкл. микрофон** | — | в своей комнате 🏠 | везде |
| **Бан** | — | — | аккаунтов и гостей (по IP) |

- 🔓 в списке значит, что пароль уже запомнен. Кнопка ✕ рядом сбрасывает его.
- 🪪 **Профиль** открывается кнопкой с вашей аватаркой на главном экране, а в комнате — нажатием на себя в списке, на ✏️ или в ⚙️ Настройках. Профиль аккаунта хранится на сервере, у гостя — в браузере.
- 🚪 **Выгнать**: нажмите на участника → «Выгнать». Вернуться в эту комнату он сможет через 10 минут. Создатель комнаты помечен 🏠.
- ⛔ **Бан** (только админ): из карточки участника или в 🛡️ админке. Срок: час, день, неделя, месяц или навсегда, можно указать причину. Аккаунт банится целиком, гость — по IP.
- 🛡️ **Админка** (кнопка рядом с профилем): все аккаунты с поиском и фильтрами, кто где онлайн, гости и их IP, баны, выдача прав и объявление всем, кто сейчас в комнатах.
- Администратор **не невидимка**: участники видят его с короной 👑. Создателю комнаты выгнать админа нельзя.
- Создать администратора можно только на сервере, через сайт нельзя:
  ```bash
  bash run.sh admin boss
  ```
- Закрыть регистрацию: укажите `ALLOW_REGISTRATION=0` в `.env` и снова запустите `run.sh`.

> 💾 Аккаунты и комнаты хранятся в docker-томе `voice-data`. Обновления и `run.sh stop` его не трогают.
> А вот `docker compose down -v` **удалит всех**.

## 📱 Телефоны

- **iPhone:** открывайте в Safari. Во время звонка не сворачивайте браузер и не блокируйте экран, иначе iOS поставит звук на паузу. Когда вернётесь, звук восстановится сам.
- **Android:** Chrome или Яндекс Браузер.
- Показывать экран с телефона нельзя: браузеры на телефонах этого не позволяют. Камера работает.
- Если не соединяется: ⚙️ → **🩺 Проверить связь с сервером**.

## 💻 Запуск на Windows

Для теста у себя или игры по локальной сети.

1. Установите **Python 3.10+**.
2. Дважды кликните **`start.bat`**: в первый раз он сам поставит зависимости.
3. Откройте `https://localhost:8443`. Браузер предупредит о самоподписанном сертификате: «Дополнительно» → «Перейти на сайт».

Или вручную:
```bash
pip install -r requirements.txt
```
```bash
python server.py
```

Чтобы позвать друга без своего сервера, можно поднять туннель Cloudflare:
```bash
python server.py --no-tls --port 8080
```
```bash
cloudflared tunnel --url http://localhost:8080
```

## ⚙️ Настройки `.env`

| Переменная | По умолчанию | Что это |
|---|---|---|
| `VOICE_PORT` | `18080` | порт на `127.0.0.1` для Caddy |
| `ALLOW_REGISTRATION` | `1` | `0` закрывает регистрацию новых аккаунтов |
| `RELAY_ONLY` | `1` | весь трафик идёт через сервер, прямых соединений нет |
| `TURN_ENABLED` | `1` | встроенный coturn |
| `TURN_EXTERNAL_IP` | авто | внешний IP сервера |
| `TURN_SECRET` | генерируется | ключ coturn, **никому не показывайте** |
| `TURN_DOMAIN` / `TURN_CERT_DIR` | авто | сертификат для TURN поверх TLS |

Пример лежит в [`.env.example`](.env.example). Настоящий `.env` создаётся на сервере и в git не попадает.

## 🧩 Как это устроено

```
 Браузер  ──HTTPS / WebSocket──▶  Caddy  ──▶  server.py   (вход, комнаты, сигналинг)
    │
    └──── WebRTC (DTLS-SRTP, зашифровано) ────▶  coturn  ────▶  Браузер друга
                                    (пересылает, но не может прочитать)
```

- **Звук и видео** идут по WebRTC с шифрованием DTLS-SRTP, ключи есть только у участников звонка.
- **Весь трафик идёт через ваш TURN.** IP участников друг другу не видны, и звонок проходит даже через строгий NAT.
- **Код безопасности** в меню участника можно сверить голосом: если цифры совпали, посредника нет.
- **Пароли** хранятся хэшами scrypt, сессии лежат в cookie с HttpOnly и SameSite, от подбора паролей стоят ограничения по IP.

```
server.py                сервер: аккаунты, комнаты, WebSocket, TURN-пароли
accounts.py              SQLite: пользователи, сессии, комнаты
public/index.html        интерфейс
public/app.js            клиент: WebRTC, обработка звука, камера, экран, чат
public/style.css         темы: тёмная, розовая, кошачья
public/gate-worklet.js   шумовой гейт
public/vendor/nsup/      RNNoise (@sapphi-red/web-noise-suppressor, MIT)
run.sh                   запуск одной командой
docker-compose.yml       voice-chat + coturn
```
